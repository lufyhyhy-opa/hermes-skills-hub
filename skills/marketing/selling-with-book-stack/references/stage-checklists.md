# Stage checklists

## S2 Offer done
- [ ] Dream outcome in buyer language
- [ ] Problems listed (not features)
- [ ] Named stack + sticker logic
- [ ] Price + who-not-for
- [ ] Guarantee If-not-X-in-Y-Z or explicit anti-guarantee reason
- [ ] MAGIC-style name draft
- [ ] ≥1 Value Equation lever vs status quo

## S3 Money model done
- [ ] Attraction named
- [ ] ≥1 upsell path
- [ ] Downsell on no (terms/features — not naked same SKU cut)
- [ ] Continuity yes/no + reason
- [ ] 30-day cash logic

## S4 Leads done
- [ ] Engaged lead = observable action
- [ ] One Core Four method + daily quota
- [ ] LM yes/no + reason
- [ ] CRM stages listed

## S6 Funnel done
- [ ] Each page one goal action
- [ ] Checkout/offer before landing polish
- [ ] Metrics per step
- [ ] Repo justified from matrix
